# PetSense

**AZ:** Pişiklər üçün ağıllı yaxalıq modulu: gündəlik aktivliyi və (GPS versiyada) yeri izləyən startup layihəsinin təqdimat saytı.
**EN:** Presentation website for PetSense, a startup project: a smart collar module that tracks a cat's daily activity and, in the GPS version, its location.

🔗 **Canlı sayt / Live site:** https://BURAYA-LINKI-YAZIN

## 🇦🇿 Azərbaycan dilində

### Layihə haqqında
PetSense pişik sahiblərinə pişiyin gündəlik aktivliyini, istirahətini və yerini izləməyə kömək edir. Cihazın iki versiyası var:

| | PetSense Basic | PetSense GPS |
|---|---|---|
| Cihaz qiyməti (birdəfəlik) | 149 AZN | 249 AZN |
| Aylıq abunə | Yoxdur | 8.90 AZN |
| Aktivlik və yuxu izləmə | ✅ | ✅ |
| Bluetooth | ✅ | ✅ |
| GPS və SIM kart | ❌ | ✅ |
| Təhlükəsiz zona və yer tarixçəsi | ❌ | ✅ |

> Qiymətlər ilkin planlaşdırma mərhələsindədir və dəyişə bilər.

### Saytın imkanları
- İki versiyanın müqayisəsi və qiymət cədvəli
- Pişiyin üzərində modulun işləməsini göstərən konsept animasiya
- Azərbaycan və İngilis dili düyməsi
- Açıq və tünd rejim
- Sifariş formu (hazırda e-poçt proqramını açır)
- Telefon və kompüterə uyğun dizayn

### Texnologiya
Sayt tək `index.html` faylıdır. Build addımı, framework və ya server tələb etmir. Yalnız HTML, CSS və JavaScript istifadə olunub. Yeganə xarici resurs Google Fonts şriftləridir.

### Yerli işə salmaq
`index.html` faylını brauzerdə açın.

### Yayımlamaq
- **GitHub Pages:** Settings → Pages → Deploy from a branch → `main` / `(root)`
- **Netlify:** repozitoriyanı bağlayın, build əmri və publish qovluğunu boş buraxın

### Vacib qeyd
PetSense tibbi cihaz deyil və xəstəlik diaqnozu qoymur. O, yalnız aktivlik və istirahət dəyişikliklərini göstərir və baytar müayinəsini əvəz etmir. Saytdakı animasiya konsept nümayişdir, real məhsul çəkilişi deyil.

## 🇬🇧 In English

### About
PetSense helps cat owners monitor their cat's daily activity, rest and location. It comes in two versions:

| | PetSense Basic | PetSense GPS |
|---|---|---|
| Device price (one-time) | 149 AZN | 249 AZN |
| Monthly subscription | None | 8.90 AZN |
| Activity and sleep tracking | ✅ | ✅ |
| Bluetooth | ✅ | ✅ |
| GPS and SIM card | ❌ | ✅ |
| Safe zone and location history | ❌ | ✅ |

> Prices are preliminary and may change.

### Website features
- Side-by-side comparison of both versions with a price table
- Concept animation showing the module on a cat's collar
- Azerbaijani / English language switch
- Light and dark mode
- Order form (currently opens the email app)
- Responsive design for phones and desktops
